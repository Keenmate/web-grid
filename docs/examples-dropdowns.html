🔽 Dropdown Features

Advanced dropdown customization with icons, subtitles, custom rendering, and async search

Dropdown Customization Demo

This grid demonstrates various dropdown customization options including custom member properties, callbacks, and rendering.

Member Properties

Map your data fields to dropdown display properties:

  • valueMember - Field for option value
  • displayMember - Field for display text
  • iconMember - Field for icon/emoji
  • subtitleMember - Field for secondary text
  • disabledMember - Field for disabled state
  • searchMember - Field for search matching

Callback Overrides

Use callbacks for complex data transformations (each takes one ctx: { option }):

  • getValueCallback({ option })
  • getDisplayValueCallback({ option })
  • getIconCallback({ option })
  • getSubtitleCallback({ option })
  • getIsDisabledCallback({ option })
  • getSearchValueCallback({ option })

Custom Option Rendering

The Priority column uses renderOptionCallback to create custom HTML for each option with colored dots.

editorOptions: {
    renderOptionCallback: ({ option: opt, ...ctx }) => {
        const classes = ['wg__dropdown-option']
        if (ctx.isFocused) classes.push('wg__dropdown-option--highlighted')
        if (ctx.isSelected) classes.push('wg__dropdown-option--selected')
        if (ctx.isDisabled) classes.push('wg__dropdown-option--disabled')
        return `<div class="${classes.join(' ')}" data-index="${ctx.optionIndex}">
            <span style="background: ${opt.color}; ..."></span>
            ${opt.label}
        </div>`
    }
}
Context Properties

The ctx object provides:

  • option - The option being rendered
  • optionIndex - Option index in the list
  • isFocused - The keyboard / mouse cursor is on it
  • isSelected - Currently selected value
  • isDisabled - Option is disabled

Dynamic Cell Styling

The Priority column also uses getCellClassCallback to apply CSS classes based on the cell value, renderCellCallback for the cell HTML, and getCustomStylesCallback to inject the matching styles into the shadow DOM.

// Column definition
{
    field: 'priority',
    getCellClassCallback: ({ value }) => value ? `priority-${value}` : null,
    renderCellCallback: ({ value }) => {
        const opt = priorityOptions.find(o => o.value === value)
        return `<span style="..."></span>${opt.label}`
    }
}

// Inject styles into shadow DOM
grid.getCustomStylesCallback = () => `
    .priority-critical { background: color-mix(in srgb, #dc3545 12%, transparent); }
    .priority-high { background: color-mix(in srgb, #fd7e14 12%, transparent); }
    .priority-medium { background: color-mix(in srgb, #ffc107 12%, transparent); }
    .priority-low { background: color-mix(in srgb, #28a745 12%, transparent); }
`
Why getCustomStylesCallback?

Since WebGrid uses Shadow DOM, external page CSS cannot reach cell elements. Use getCustomStylesCallback to inject CSS rules that target classes added by getCellClassCallback.
