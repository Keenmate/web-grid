Context Menu

Right-click context menus for cells and column headers with dynamic items and conditional visibility

Read-Only Grid with Context Menu

Right-click any cell to see the context menu. Try "Copy Cell" to see dynamic labels based on column. Right-click the Price column to see the "Convert to Euro" option.

Editable Grid with Context Menu

Right-click to see context-aware options. Note: "Delete" is disabled for active products, "Restock" only appears for low-stock items (stock < 20).

Context Menu API

Grid Properties

contextMenuArray of entries: built-in names ('add', 'duplicate', 'delete', 'move-up', 'move-down', tree 'expand'…), menu items, dividers
contextMenuXOffsetHorizontal offset from click (default: 8)
contextMenuYOffsetVertical offset from click (default: 0)
beforeContextMenuOpenCallbackRuns before the menu opens (sync): false → no grid menu, an entries array → shown instead
onAction / action eventFired for every item click (source: 'context-menu')

Menu Item Properties

actionBuilt-in name (omit for a custom item)
idIdentifies a custom item
text / getTextCallbackDisplay text (static or per ctx)
icon / getIconCallbackEmoji or HTML icon
shortcutKey hint; pressing it while the menu is open activates the item
isDisabled / getIsDisabledCallbackDisabled state
isVisible / getIsVisibleCallbackVisibility
isDangerRed styling for destructive actions
children / getChildrenCallbackSubmenu (static, or lazy / async)
{ divider: true, text? }A divider entry (optionally labelled)
onClickClick handler receiving the action detail

Context Object

The cell context passed to item callbacks (and, plus action / id / source, to onClick):

rowThe row data object
rowIndexIndex of the row
colIndexIndex of the column
column / fieldThe column definition / its field
valueThe value of the clicked cell
controller / elementThe grid controller (el.controller) and the host element
grid.contextMenu = [
    {
        id: 'copy',
        getTextCallback: (ctx) => `Copy "${ctx.column.title}"`,
        icon: '📋',
        shortcut: 'C',  // Press C while the menu is open
        onClick: (detail) => {
            navigator.clipboard.writeText(String(detail.value))
        }
    },
    { divider: true },
    // Built-in: removes the row itself
    {
        action: 'delete',
        icon: '🗑️',
        isDanger: true,
        getIsDisabledCallback: (ctx) => ctx.row.isProtected
    }
]

Menu Position Offset

Control where the context menu appears relative to the click position. Adjust the sliders and right-click to see the effect.

Header Context Menu

Right-click on column headers to access column-specific actions like sorting, freezing, and hiding. Supports predefined actions (string shortcuts) and custom items.

Right-click a column header to see the context menu...

Header Context Menu API

Grid Properties

headerContextMenuArray of built-in names, menu items and dividers
beforeHeaderMenuOpenCallbackRuns before the header menu opens (sync): false → no grid menu, an entries array → shown instead

Predefined Actions

'sort-asc'Sort ascending
'sort-desc'Sort descending
'clear-sort'Clear sort (auto-hides if not sorted)
'hide-column'Remove column from grid
'freeze-column'Freeze up to this column
'unfreeze-column'Unfreeze this column
'column-visibility'Submenu toggling each column's visibility

HeaderMenuContext

The context passed to header menu callbacks:

columnThe column definition (null on the filler area right of the last column)
fieldColumn field name ('' on the filler)
colIndexIndex of the column (-1 on the filler)
sortDirection'asc' | 'desc' | null
isFrozenWhether column is frozen
grid.headerContextMenu = [
    'sort-asc',
    'sort-desc',
    'clear-sort',
    { divider: true },
    'freeze-column',
    'unfreeze-column',
    { divider: true },
    {
        id: 'export',
        getTextCallback: (ctx) => `Export ${ctx.field}`,
        getIsVisibleCallback: (ctx) => ctx.column !== null,  // hide on the filler
        icon: '📊',
        onClick: (detail) => exportColumn(detail.field)
    }
]
