⌨️ Keyboard Shortcuts

Grid-level keyboard shortcuts for row operations with help overlay

Row Keyboard Shortcuts

Click on any cell to focus it (navigate mode), then use the keyboard shortcuts below. Press F2 or Enter to edit. Hover over the ⓘ icon to see available shortcuts.

Available Shortcuts

Ctrl+Delete Delete row
Ctrl+D Duplicate row
Ctrl+U Move row up
Ctrl+M Move row down
F2 Edit cell (built-in navigation key)
Ctrl+E Export row

Configuration

// Enable navigate mode for cell focus
grid.isEditable = true
grid.editTrigger = 'navigate'

// Row built-ins do the work: 'delete' removes the row,
// 'duplicate' inserts createDuplicateRowCallback's copy
grid.createDuplicateRowCallback = ({ row }) => ({ ...row, id: nextId++ })

grid.rowShortcuts = [
  { shortcut: 'Ctrl+Delete', action: 'delete', text: 'Delete row' },  // plain Delete clears the cell in navigate mode
  { shortcut: 'Ctrl+D', action: 'duplicate', text: 'Duplicate row' },
  {
    shortcut: 'Ctrl+U',
    id: 'move-up',
    text: 'Move row up',
    getIsDisabledCallback: ({ rowIndex }) => rowIndex === 0,
    // custom item: move via the controller, keep focus on the moved row
    onClick: ({ row, rowIndex, colIndex, controller }) => {
      controller.moveRow(row, -1)
      controller.focusCell(rowIndex - 1, colIndex)
    }
  }
]

// Every shortcut also fires the `action` event (source: 'keyboard')
grid.onAction = ({ action, id, rowIndex }) => {
  console.log(action === 'custom' ? id : action, rowIndex)
}

// Show help icon
grid.isShortcutsHelpShown = true

API Reference

Grid Properties

rowShortcutsArray of shortcut definitions
isShortcutsHelpShownShow info icon (default: false)
shortcutsHelpPosition'top-right' | 'top-left'
renderShortcutsHelpCallbackCustom HTML for overlay

Shortcut Item Properties (GridShortcut)

shortcutKey combo (e.g., "Ctrl+Delete", "Ctrl+D", "Shift+F3")
actionA row built-in to run: 'add' | 'delete' | 'duplicate' | 'move-up' | 'move-down' (optional)
idIdentifies a custom item (in the action event)
textLabel for the help overlay
onClickCalled with the action detail (custom items)
isDisabled / getIsDisabledCallbackStatic flag or per-row callback (optional)

Action Detail

The detail passed to onClick, getIsDisabledCallback and the action event (plus controller and element):

rowThe row data object
rowIndexIndex of the focused row
colIndexIndex of the focused column
columnThe column definition
valueValue of the focused cell

Key Format

Supported modifier keys:

  • Ctrl+ or Control+
  • Shift+
  • Alt+
  • Meta+ or Cmd+

Examples: Ctrl+Delete, Ctrl+D, Shift+F3, Ctrl+Alt+E. In navigate mode the grid's own keys (arrows with any modifier, F2, Enter, plain Delete, printable characters) are handled before row shortcuts, so bind shortcuts to other chords.
