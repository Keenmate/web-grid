Theming scenarios — dark-mode signals

Each card mounts the same <web-grid> under one dark-mode signal. The e2e spec at e2e/theming.spec.ts asserts the rendered cell background reflects the expected mode (light vs dark) per signal.

1. No signal (baseline light)

No attribute, no ancestor class. Expected: LIGHT.

2. Per-instance data-theme="dark"

Attribute on <web-grid> directly. Expected: DARK.

3. Per-instance data-theme="light"

Attribute forces light even on a dark page. Expected: LIGHT.

4. Ancestor [data-theme="dark"]

Generic framework convention. Expected: DARK.

5. Ancestor [data-bs-theme="dark"]

Bootstrap 5.3+ convention. Expected: DARK.

6. Ancestor .dark (Tailwind)

Tailwind class-mode dark convention. Expected: DARK.

7. Ancestor [data-theme="light"]

Forces light. Expected: LIGHT.
