web-grid — e2e test fixtures

Minimal, deterministic pages targeted by the Playwright suite in e2e/. Each page configures only what its spec asserts on and surfaces grid state through data-testid nodes. Not part of the published docs — see ../index.html for the demo site.

  • basic — render, sorting, editing, keyboard nav, pagination, formatting, row locking, feature toggles
  • editors — text / select / checkbox / custom editors + cell context menu
  • fill-handle — Excel-like autofill drag (basic / cancel / vertical / horizontal)
  • freeze-panes — grid-level frozenColumnCount, sticky row numbers, column-level isFrozen
  • resize-reorder — column resize, persistence, drag-to-reorder, header context menu
  • toolbar — floating / multi-row / inline / cell-aware row toolbars
  • tree — tree mode, Ctrl+Arrow shortcuts, Tab navigation, column visibility
  • selection — row / column / cell-range selection and row focus
  • validation — validateCallback (string / result object / transform)
  • shortcuts — rowShortcuts keyboard actions on the focused row
  • edit-trigger — editTrigger modes (click / dblclick / navigate)
  • dropdowns — select / combobox / autocomplete editors in depth
  • grid-modes — the mode preset (read-only / excel / input-matrix)
  • height-modes — capped max-height vs isTableBorderOnly full-height
  • custom-styling — cellClass / cellClassCallback / rowClassCallback / templateCallback / getCustomStylesCallback
  • column-visibility — column.isHidden via API + the predefined hideColumn / columnVisibility header context menu items
  • contextmenu — cell context menu (dynamic labels, visible / disabled / danger / divider / shortcut) + header context menu predefined & custom items
  • paste — single-cell and multi-cell TSV paste, header detection, paste modes, new-row creation, beforePasteCallback cancel
  • virtual-scroll — virtual scroll over 1,000 rows (spacer pattern, scroll-driven re-render) + infinite scroll (ondatarequest mode='append')
  • tree-scroll — tree mode combined with virtual scroll (3-level tree, expand/collapse) + infinite scroll (append subtrees)
  • theme-context — core theme context (page signal → data-context-theme), --base-* chain
  • inputs — module-only page; inputs.spec mounts grids on the fly
  • filter-row — built-in filter row (isFilterable + column.isFilterable): debounce, page 1, invalid filterCallback input, server mode + beforePageChangeCallback
  • datepicker — date editor: open / select / keyboard nav, min/max constraints, dateFormat / outputFormat (iso / timestamp)
