filter row

Targeted by e2e/filter-row.spec.ts — and a demo of the built-in filter row (NOTES.md #4). A grid with filterable shows a row under the header; columns with isFilterable: true get a text input (labelled "Filter <column>"). Typing is debounced (300 ms; Enter applies at once, Esc clears) → setFilter → page 1. The salary column has a filterCallback (>N / <N / N); a lone > is incomplete → null → red border, filter ignored.

#grid — client filtering + pagination (13 rows, page-size 4)

#server — server pagination: a filter change runs beforePageChangeCallback (trigger 'filter') and fires data-request (trigger 'filter')
