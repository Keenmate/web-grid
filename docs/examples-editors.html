Custom Editor

Use editor: "custom" with renderEditorCallback for dialog-based editing.

{
    field: 'notes',
    editor: 'custom',
    renderEditorCallback: (context) => {
        // context contains:
        // - value: current cell value
        // - row: full row data
        // - rowIndex: row index
        // - field / column / colIndex: the column
        // - commit(newValue): save and close
        // - cancel(): discard and close

        const newValue = prompt('Edit:', context.value)
        if (newValue !== null) {
            context.commit(newValue)
        } else {
            context.cancel()
        }
    }
}
Triggers

Custom editor opens on: F2, Space, double-click, or navigate mode entry

Context Menu

Set contextMenu array on the grid element.

grid.contextMenu = [
    {
        id: 'copy',
        text: 'Copy value',
        icon: '📋',
        onClick: (ctx) => {
            navigator.clipboard.writeText(ctx.value)
        }
    },
    { divider: true },
    {
        id: 'delete',
        text: 'Delete row',
        icon: '🗑️',
        isDanger: true,
        getIsDisabledCallback: (ctx) => ctx.row.protected,
        onClick: (ctx) => { ... }
    }
]

Context Menu Item Properties

Static Properties

  • id - Identifies a custom item
  • action - A built-in instead ('add', 'duplicate', 'delete', 'move-up', 'move-down', tree 'expand'…)
  • text - Display text
  • icon - Emoji or HTML for icon
  • shortcut - Key hint (also activates the item while the menu is open)
  • isDanger - Red styling for destructive actions
  • { divider: true, text? } - A separator entry (optionally labelled)

Dynamic Properties

  • isVisible / getIsVisibleCallback(ctx) - Show/hide
  • isDisabled / getIsDisabledCallback(ctx) - Disable item
  • getTextCallback(ctx) / getIconCallback(ctx) - Dynamic text / icon
  • children / getChildrenCallback(ctx) - Submenu
  • onClick(detail) - Click handler (also reported by the action event / onAction)

Context Object

  • value - Cell value
  • row - Full row data
  • rowIndex - Row index
  • field - Column field name
  • column / colIndex - Column definition / index
  • controller / element - The grid controller and host element
