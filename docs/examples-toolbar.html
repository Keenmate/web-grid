🛠️ Row Toolbar

Floating toolbar with row actions, rich tooltips, and keyboard shortcuts

Controls

Horizontal Align only applies when toolbar appears above the row (top position).
Toolbar Column positions the toolbar over a specific column (overrides horizontal align).
Follow Cursor makes the toolbar follow your mouse horizontally.
Cell Toolbar Offset controls horizontal position within the cell. Number 0-1 as fraction (0.2 = 20% from left), or CSS length (e.g. "2rem", "24px").
Btn Min Width sets minimum width for toolbar buttons (e.g. "40px"). Leave empty for default.

Tasks List with Row Actions

Hover over a row to see the toolbar. Press D to duplicate, Delete to delete, or ↑/↓ to move.

Built-in Toolbar Items

Use these built-in names (as strings, or as action on an item to override its icon / text) for common row actions. Built-ins do the work after the action event: you don't insert / remove / move the row yourself.

action Icon Action
addInsert createEmptyRowCallback(ctx)'s row (else a blank row) below
deleteDelete current row (danger style)
duplicateInsert createDuplicateRowCallback({ row })'s copy (else a shallow copy, idMember cleared) below
move-upSwap with the displayed row above
move-downSwap with the displayed row below

Usage

// Enable toolbar with built-in actions
grid.isRowToolbarShown = true
grid.rowToolbar = ['add', 'delete', 'duplicate', 'move-up', 'move-down']
grid.toolbarTrigger = 'hover' // or 'click', 'button'

// Shape the rows the built-ins insert
grid.createEmptyRowCallback = () => ({ id: nextId++, title: 'New Task' })
grid.createDuplicateRowCallback = ({ row }) => ({ ...row, id: nextId++ })

// Every click fires the `action` event (+ the onAction twin) —
// the built-in runs right after it, so only react here (toast, log, save)
grid.onAction = ({ action, id, row, rowIndex, source }) => {
    console.log(action, id, 'on row', rowIndex, 'from', source)
}

// Veto any item (async OK, e.g. a confirm dialog)
grid.beforeActionCallback = ({ action, row }) => {
    if (action === 'delete') return confirm(`Delete ${row.title}?`)
}

Custom Toolbar Items

Define custom items (an id, no built-in action) with icons, texts, and handlers:

grid.rowToolbar = [
    'add',  // Built-in shorthand
    'delete',
    { divider: true },
    {
        id: 'archive',
        icon: '📦',
        text: 'Archive row',
        onClick: ({ row, rowIndex }) => {
            console.log('Archiving row:', row)
        }
    },
    {
        id: 'lock',
        icon: '🔒',
        text: 'Lock row',
        getIsDisabledCallback: ({ row }) => row.locked,  // Dynamic disabled state
        getIsToggledCallback: ({ row }) => row.flagged,   // Toggle state (aria-pressed)
        onClick: ({ row }) => {
            row.locked = true
        }
    }
]

Rich Tooltips

Toolbar buttons show a rich tooltip: text is the heading, tooltip the description, shortcut the key line. Hover over a button to see it in action!

// Static tooltip with description
grid.rowToolbar = [
    {
        action: 'duplicate',
        icon: '⧉',
        text: 'Duplicate',
        tooltip: 'Create a copy of this task',
        shortcut: 'D'  // Optional - auto-detected from rowShortcuts
    }
]

// Dynamic tooltip with a callback
grid.rowToolbar = [
    {
        id: 'info',
        icon: 'ℹ',
        text: 'Info',
        // the description renders as HTML: escape row data
        getTooltipCallback: ({ row }) => `Task #${row.id} · ${esc(row.title)}`
    }
]

Note: When toolbar items have a matching rowShortcuts entry (same id or built-in action), the keyboard shortcut is automatically shown in the tooltip.

Keyboard Shortcuts on Hover

When the toolbar is visible (hovering over a row), keyboard shortcuts work on that row - no cell focus required!

// Shortcuts are action items bound to a key; `action` may name a row built-in
grid.rowShortcuts = [
    { shortcut: 'd', action: 'duplicate', text: 'Duplicate row' },
    { shortcut: 'Delete', action: 'delete', text: 'Delete row' },
    { shortcut: 'ArrowUp', action: 'move-up', text: 'Move up' },
    {
        shortcut: 'e',
        id: 'export',
        text: 'Export row',
        onClick: ({ row, rowIndex }) => exportRow(row)  // custom item
    }
]

Multi-Row Toolbar with Dividers

Use the row property and { divider: true } entries to organize toolbar buttons into multiple rows and groups:

// Row 1: Move actions | CRUD actions
// Row 2: Custom actions (one with a visible text label)
grid.rowToolbar = [
    { action: 'move-up', icon: '↑', text: 'Move up', row: 1 },
    { action: 'move-down', icon: '↓', text: 'Move down', row: 1 },
    { divider: true },
    { action: 'add', icon: '+', text: 'Add', row: 1 },
    { action: 'duplicate', icon: '⧉', text: 'Duplicate', row: 1 },
    { action: 'delete', icon: '−', text: 'Delete', isDanger: true, row: 1 },

    { id: 'export', icon: '📤', text: 'Export row', row: 2 },
    { id: 'preview', icon: '👁', text: 'View', isTextVisible: true, row: 2 },
    { divider: true },
    { id: 'archive', icon: '📦', text: 'Archive', row: 2 }
]

Cell-Aware Toolbar

Use the getCellToolbarItemsCallback callback to show different toolbar options based on which cell the user is hovering over (merged over rowToolbar by id / action). Combined with shouldToolbarFollowCursor, the toolbar follows your mouse and updates its buttons per column.

grid.toolbarPosition = 'top'
grid.shouldToolbarFollowCursor = true  // Toolbar follows mouse
grid.cellToolbarOffset = 0.2     // Position at 20% from cell left edge (0-1)

// Different actions per column (ctx: row, rowIndex, column, colIndex, field, value)
grid.getCellToolbarItemsCallback = ({ field }) => {
    switch (field) {
        case 'priority':
            return [
                { id: 'setHigh', icon: '🔴', text: 'Set High' },
                { id: 'setMedium', icon: '🟡', text: 'Set Medium' },
                { id: 'setLow', icon: '🟢', text: 'Set Low' }
            ]
        case 'status':
            return [
                { id: 'setTodo', icon: '📋', text: 'Set Todo' },
                { id: 'setProgress', icon: '🔄', text: 'Set In Progress' },
                { id: 'setDone', icon: '✅', text: 'Set Done' }
            ]
        default:
            return undefined  // Use default toolbar
    }
}

grid.onAction = ({ id, row }) => { /* id === 'setHigh', ... */ }

Inline Actions Column

Use toolbarPosition="inline" to render toolbar buttons as a fixed column instead of a floating popup. Buttons are always visible, with support for getIsDisabledCallback and getIsVisibleCallback per row. Keyboard shortcuts via rowShortcuts work when hovering over a row (try Delete or A); beforeActionCallback vetoes deleting high-priority tasks.

grid.isRowToolbarShown = true
grid.toolbarPosition = 'inline'  // Renders as column
grid.labels = { inlineActionsHeader: 'Actions' }  // Optional header ('' = blank)

grid.rowToolbar = [
    {
        id: 'edit',
        icon: '✏️',
        text: 'Edit',
        getIsDisabledCallback: ({ row }) => row.status === 'Done'  // Disable for completed tasks
    },
    {
        action: 'delete',
        icon: '🗑️',
        text: 'Delete',
        getIsVisibleCallback: ({ row }) => row.priority !== 'High'  // Hide for high priority tasks
    },
    {
        id: 'archive',
        icon: '📦',
        text: 'Archive'
    }
]

// The Delete shortcut doesn't see the button's visibility — veto it here
grid.beforeActionCallback = ({ action, row }) => {
    if (action === 'delete' && row.priority === 'High') return false
}
