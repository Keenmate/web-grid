CALLBACKS AND EVENTS
====================
@keenmate/web-grid - Complete reference for all callbacks and events.


NAMING CONVENTION
-----------------
Events          - real DOM events with kebab-case names (row-change, action, ...)
                  plus a camelCase on* twin property (onRowChange, onAction, ...).
                  Fire-and-forget: return values are ignored.
*Callback       - callbacks whose return value affects component behavior
                  (get*Callback returns a value, render*Callback returns HTML,
                  before*Callback can veto with false, create*Callback builds rows).

Every callback takes ONE argument: a ctx object. Every ctx and every event
detail carries `controller` (the public GridController, also el.controller)
and `element` (the <web-grid> host). Both are non-enumerable, so
JSON.stringify / console.log show only the data.

    grid.getRowClassCallback = ({ rowIndex, controller }) =>
      controller.isRowDirty(rowIndex) ? 'row-dirty' : null


EVENTS
------
Events bubble (they are NOT composed). Listen either way:

    grid.addEventListener('row-change', (e) => save(e.detail))
    grid.onRowChange = (detail) => save(detail)     // twin, called with the detail first

The twin receives the detail object (not the CustomEvent).

row-change / onRowChange
  Detail: { row, draftRow, rowIndex, field, oldValue, newValue, isValid, validationError }
  Fires when a cell value is committed (editor, checkbox, paste, new row).
  The row is the original (unchanged). draftRow contains the user's edits
  including invalid values.

edit-start / onEditStart
  Detail: { row, rowIndex, field }
  Fires when a cell editor opens.

edit-cancel / onEditCancel
  Detail: { row, rowIndex, field }
  Fires when the user cancels an edit (Escape key).

validation-error / onValidationError
  Detail: { row, rowIndex, field, error, source: 'edit' | 'paste' }
  Fires when column.validateCallback rejects a value (editor commit or paste).

action / onAction
  Detail: GridActionEventDetail<T> = { action, id?, item, source, sourceEvent?,
          triggerElement?, dataset, ...surface fields }
  Fires for every toolbar, inline, cell-toolbar, menu and shortcut item.
  action: built-in name ('add', 'sort-asc', ...) or 'custom'
  source: 'row-toolbar' | 'cell-toolbar' | 'context-menu' | 'header-menu' | 'keyboard'
  Surface fields: row / rowIndex (+ column / colIndex / field / value on
  cell surfaces), the HeaderMenuContext fields in the header menu, rows /
  rowIndices (/ cellRange / cells) for range shortcuts.
  triggerElement is the clicked button (inside the shadow DOM) - usable as
  a Floating UI anchor for popovers.
  Fires after the item's onClick AND after the built-in has run (a
  notification after the fact: after 'delete' the row is gone from items,
  after 'add' the new row is present, after 'move-*' the new order). See
  toolbar-actions.txt.

data-request / onDataRequest
  Detail: { sort, page, pageSize, trigger, mode, skip }
  Fires when sort (incl. a header-menu sort), page, or pageSize changes,
  or more rows are needed (infinite scroll).
  trigger: 'sort' | 'page' | 'page-size' | 'init' | 'load-more'
  mode: 'replace' | 'append' (append for infinite scroll loadMore)

filter-change / onFilterChange
  Detail: { filters }   (current filter value per field)
  Fires when a column filter changes. With filterMode = 'server'
  (attribute filter-mode="server") the grid does not filter locally -
  the consumer filters and sets items.

row-delete / onRowDelete
  Detail: { row, rowIndex }
  Fires when Ctrl+Delete is pressed on a row. A REQUEST - the grid does
  not delete; remove the row yourself.

row-focus / onRowFocus
  Detail: { rowIndex, row, previousRowIndex }
  Fires when a different row is focused (useful for master/detail patterns).

row-lock-change / onRowLockChange
  Detail: { rowId, row, rowIndex, lockInfo, source }
  Fires when a row's lock state changes.
  source: 'property' | 'callback' | 'external'

column-resize / onColumnResize
  Detail: { field, oldWidth, newWidth, allWidths }
  Fires when a column is resized by dragging.

column-reorder / onColumnReorder
  Detail: { field, fromIndex, toIndex, allOrder }
  Fires when a column is reordered by dragging.

cell-selection-change / onCellSelectionChange
  Detail: { range: CellRange | null, cellCount: number, fields: string[], rows: T[] }
  Fires when the cell range selection changes. range.startColIndex /
  endColIndex are ON-SCREEN (visual) positions, not indices into columns;
  fields = the range's columns in on-screen order; rows = the row objects in
  the range (each once, display order). Cleared: { range: null, cellCount: 0,
  fields: [], rows: [] }.

row-selection-change / onRowSelectionChange
  Detail: { rows: T[], rowIndices: number[] }
  Fires when the row selection changes: row-number click / Ctrl / Shift /
  drag, selectRow / selectRowRange / clearSelection, or rows cleared by a
  cell / column selection.

column-selection-change / onColumnSelectionChange
  Detail: { fields: string[] }   (on-screen order)
  Fires when the column selection changes: header click / Ctrl / Shift /
  drag, controller.selectColumn / selectColumnRange / clearColumnSelection,
  or columns cleared by another selection.

  The three selection events fire once per gesture / API call (a drag
  notifies on mouseup) and only when that selection actually changed.

expand-change / onExpandChange
  Detail: { path, isExpanded, expandedPaths }
  Fires when tree rows are expanded / collapsed (toggle, subtree,
  expand / collapse all - path is null for the "all" operations).

paste-complete / onPasteComplete
  Detail: { totalCells, successfulCells, failedCells, skippedCells,
  newRowsCreated, cellResults, hadHeaders }
  Fires after a multi-cell paste is applied.


GRID-LEVEL CALLBACKS (RETURN VALUE MATTERS)
-------------------------------------------

beforeActionCallback
  Signature: (detail: GridActionEventDetail<T>) => unknown
  Runs before any toolbar / menu / shortcut item activates. Return false
  (or a Promise resolving to false) to cancel - e.g. a confirm dialog.

beforeContextMenuOpenCallback
  Signature: (ctx: CellContext<T>) => false | GridMenuEntry<T>[] | void
  Sync. Runs before the cell context menu opens. false -> no grid menu
  (the browser's menu shows); an entries array -> shown instead of contextMenu.

beforeHeaderMenuOpenCallback
  Signature: (ctx: HeaderMenuContext<T>) => false | GridHeaderMenuEntry<T>[] | void
  Same contract for the header context menu.

beforePasteCallback
  Signature: (ctx: BeforePasteContext<T>) => boolean | void | Promise<boolean | void>
  Runs before a multi-cell paste is applied. Return false to cancel.
  ctx: { rawText, parsedRows, hasHeaders, headerMapping, targetRowIndex,
  targetColIndex, newRowsCount, skipCells }
  Add "rowIndex-colIndex" keys to ctx.skipCells to skip specific cells.

beforePageChangeCallback
  Signature: (ctx: BeforePageChangeContext<T>) => boolean | number | void | Promise<…>
  Runs before a user action swaps the displayed rows: pager buttons, page-size
  change, header sort and filter-row changes in server pagination.
  ctx: { trigger: 'page' | 'page-size' | 'sort' | 'filter', fromPage, toPage,
  drafts }   (drafts = getDrafts(): every unsaved draft)
  false → stay; nothing → continue; a number → go to that page instead.
  Async OK: the pager is disabled (aria-busy) and further navigation ignored
  while it is pending. Programmatic currentPage writes and infinite-scroll
  loadMore skip it. Use: force "save before leaving the page", or allow
  batch editing across pages.

beforeFillCallback
  Signature: (ctx: FillContext<T>) => boolean | void | Promise<boolean | void>
  Runs when a fill-handle drag completes. Return false to cancel the fill.
  ctx: { sourceCell, targetCells, direction }

getCellToolbarItemsCallback
  Signature: (ctx: CellContext<T>) => GridToolbarEntry<T>[] | null | undefined
  Cell-specific toolbar items, merged over rowToolbar by id / action.

getPaginationLabelsCallback
  Signature: (ctx: PaginationLabelsContext<T>) => Partial<PaginationLabels>
  ctx: { currentPage, totalPages, totalItems, pageSize }
  Returns translated/customized pagination text labels.

renderSummaryCallback
  Signature: (ctx: SummaryContext<T>) => string
  ctx: { items, allItems, totalItems, currentPage, pageSize, metadata, drafts }
  drafts: every unsaved draft { row, draftRow, changedFields, isValid } (also on
  other pages) — adjust server aggregates (metadata) by the draft deltas.
  Returns HTML string for the summary bar content.

getCustomStylesCallback
  Signature: (ctx: GridContext<T>) => string
  Returns CSS string injected into the shadow DOM.

getRowClassCallback
  Signature: (ctx: RowContext<T>) => string | null
  ctx: { row, rowIndex }
  Returns CSS class name(s) to apply to a row element.

getIsRowEditableCallback
  Signature: (ctx: RowDataContext<T>) => boolean
  ctx: { row }. Per-row editability (isRowEditable is the static boolean).

getIdCallback
  Signature: (ctx: RowDataContext<T>) => unknown
  ctx: { row }. Computed row id; wins over idMember (default 'id').

getValidationTooltipCallback
  Signature: (ctx: ValidationTooltipContext<T>) => string | null
  ctx: the cell ctx + error. Returns HTML for validation error tooltips
  (grid-level default).

renderShortcutsHelpCallback
  Signature: (ctx: GridContext<T>) => string
  Returns custom HTML to display alongside the shortcuts help list.

renderChevronCallback
  Signature: (ctx: ChevronContext<T>) => string
  ctx: { row, isExpanded, hasChildren, level, path }
  Returns HTML for the tree chevron (cached per row + expanded state).

createRowCallback
  Signature: (ctx: CreateRowContext<T>) => T
  ctx: { data, rowIndex } - data is the pasted values by field.
  Creates a new row object when a paste adds rows beyond the current items.
  Required for multi-row paste to create new rows.

createEmptyRowCallback
  Signature: (ctx: GridContext<T>) => T | Promise<T>
  Creates a blank row for the new-row entry feature (isNewRowEnabled) and
  for the 'add' built-in action (toolbar / menu / shortcut).

createDuplicateRowCallback
  Signature: (ctx: RowContext<T>) => T
  ctx: { row, rowIndex }. The copy the 'duplicate' built-in inserts
  (default: shallow copy with idMember cleared).


ROW LOCKING CALLBACKS (ON rowLocking)
-------------------------------------

getIsLockedCallback:        (ctx: RowContext<T>) => boolean
getLockInfoCallback:        (ctx: RowContext<T>) => RowLock | null
getCanEditLockedCallback:   (ctx: RowLockContext<T>) => boolean    ctx: { row, rowIndex, lockInfo }

See row-locking.txt.


COLUMN-LEVEL CALLBACKS (ON COLUMN<T>)
--------------------------------------
Most column callbacks receive the cell ctx (CellContext<T>):
{ row, rowIndex, column, colIndex, field, value } (+ controller, element).

getDisplayValueCallback
  Signature: (ctx: CellContext<T>) => string
  Returns the display string for the cell value. Text only (escaped).

renderCellCallback
  Signature: (ctx: CellContext<T>) => string
  Returns HTML string for custom cell content (wins over getDisplayValueCallback).

getTooltipCallback
  Signature: (ctx: CellContext<T>) => string | null
  Returns tooltip text for the cell. Takes priority over tooltipMember.

getCellClassCallback
  Signature: (ctx: CellContext<T>) => string | null
  Returns dynamic CSS class name(s) for cells in this column.

getIsEditableCallback
  Signature: (ctx: RowDataContext<T>) => boolean
  ctx: { row }. Per-row editability of the column (isEditable is the static boolean).

filterCallback
  Signature: (ctx: FilterContext<T>) => boolean | null
  ctx: { filterValue, row, column, field }. Custom filter predicate.

validateCallback
  Signature: (ctx: ValidateContext<T>) => ValidateResult | Promise<ValidateResult>
  Validates and optionally transforms a value before commit (editor) or
  on paste (with shouldValidateOnPaste).
  ctx: the cell ctx + { value (candidate), oldValue, source: 'edit' | 'paste' }
  Return values:
    { valid: true }                          Accept
    { valid: true, transformedValue: x }     Accept with transformation
    { valid: false, message: 'Error' }       Reject with message
    true / null / undefined                  Accept
    false                                    Reject (no message)
    'Error message'                          Reject with that string as message

renderEditorCallback
  Signature: (ctx: EditorContext<T>) => void
  Handler for editor: 'custom'. ctx: the cell ctx + commit(newValue) / cancel().

getValidationTooltipCallback (column-level)
  Signature: (ctx: ValidationTooltipContext<T>) => string | null
  Returns HTML for this column's validation error tooltip. Overrides grid-level.

getCopyValueCallback
  Signature: (ctx: CellContext<T>) => string
  The text copied to the clipboard for this cell.

getPasteValueCallback
  Signature: (ctx: PasteValueContext<T>) => unknown
  ctx: the cell ctx + text (the pasted text). Returns the value to store.


EDITOR OPTION CALLBACKS (ON EDITOROPTIONS<T>)
----------------------------------------------
These are set inside column.editorOptions for select, combobox, and
autocomplete editor types. Option callbacks receive ({ option }).

getValueCallback
  Signature: ({ option }) => string | number
  Returns the value to store from an option.

getDisplayValueCallback
  Signature: ({ option }) => string
  Returns the display text for an option.

getSearchValueCallback
  Signature: ({ option }) => string
  Returns searchable text (falls back to display text).

getIconCallback
  Signature: ({ option }) => string
  Returns icon/emoji for an option.

getSubtitleCallback
  Signature: ({ option }) => string
  Returns subtitle/description for an option.

getIsDisabledCallback
  Signature: ({ option }) => boolean
  Returns whether an option is disabled.

getGroupCallback
  Signature: ({ option }) => string
  Returns group name for grouping options.

renderOptionCallback
  Signature: (ctx: OptionRenderContext<T>) => string
  ctx: { option, index, isHighlighted, isSelected, isDisabled }
  Returns custom HTML for rendering an option in the dropdown.

onSelect
  Signature: (ctx: OptionSelectContext<T>) => void
  ctx: the cell ctx + option. Fire-and-forget; fires when an option is selected.

searchCallback (autocomplete only)
  Signature: (ctx: OptionSearchContext<T>) => Promise<EditorOption[]>
  ctx: the cell ctx + { term, signal }. signal is aborted when a newer
  search starts.


ITEM CALLBACKS (TOOLBAR, MENUS, SHORTCUTS)
-------------------------------------------
All items are action items (see toolbar-actions.txt). ctx is the surface
ctx: RowContext (toolbar), CellContext (cell menu, cell toolbar, row
shortcuts), HeaderMenuContext (header menu), RangeContext (range shortcuts).

onClick(detail)                 runs on activation; detail = the action event detail; awaited
getTextCallback(ctx)            dynamic text
getIconCallback(ctx)            dynamic icon
getTooltipCallback(ctx)         dynamic tooltip
getClassCallback(ctx)           dynamic CSS classes
getIsVisibleCallback(ctx)       dynamic visibility
getIsDisabledCallback(ctx)      dynamic disabled state
getIsToggledCallback(ctx)       dynamic toggle state
getChildrenCallback(ctx)        menus only: dynamic / lazy submenu (sync or async)

Static forms: text, icon, tooltip, cssClass, isVisible, isDisabled,
isToggled, isDanger, children.
