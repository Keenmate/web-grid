TYPESCRIPT TYPES
================
@keenmate/web-grid - Key exported types reference.

Types are exported from the package entry point:
  import type { Column, EditorOptions, SortState, GridController, CellContext } from '@keenmate/web-grid'

Runtime exports: GridElement (also the default export; auto-registers
<web-grid>), GridEngine (the state engine, for standalone / advanced use -
not the element's public API) and menuDivider (divider factory for
toolbar / menu entry lists).


----------------------------------------------------------------------
INTERACTION MODEL BASICS
----------------------------------------------------------------------
Every callback takes ONE ctx argument. Every ctx and every event detail
extends GridContext<T>, which carries two NON-ENUMERABLE fields:

  type GridContext<T> = {
    controller: GridController<T>   the public facade (also el.controller)
    element: HTMLElement            the <web-grid> host
  }

JSON.stringify / console.log of a ctx show only the data fields.


----------------------------------------------------------------------
GRIDCONTROLLER<T>
----------------------------------------------------------------------
el.controller, and `controller` on every ctx / detail.

  interface GridController<T> {
    // data
    items: T[]
    displayItems: T[]                       filtered, sorted, paginated, tree-collapsed
    columns: Column<T>[]
    sort: SortState[]
    filters: Record<string, string>
    setFilter(field: string, value: string): void
    // rows (used by the add / delete / duplicate / move-up / move-down built-ins)
    insertRow(row: T, afterRow?: T | null): void
    insertRows(rows: T[], afterRow?: T | null): void
    removeRow(row: T): void
    removeRows(rows: T[]): void
    duplicateRow(row: T): T
    moveRow(row: T, delta: -1 | 1): void
    getRowId(row: T): unknown | undefined
    getRowById(id: unknown): T | null
    getRowIndex(row: T): number         display index, -1 when not displayed
    updateRowById(id: unknown, newData: Partial<T>): boolean
    replaceRowById(id: unknown, newRow: T): boolean
    // drafts / validation
    getRowDraft(rowIndex: number): T | undefined
    hasRowDraft(rowIndex: number): boolean
    getDraftRowIndices(): number[]
    getDrafts(): DraftInfo<T>[]    { row, draftRow, changedFields, isValid }
    discardDraft(row: T): void
    discardAllDrafts(): void
    isCellDirty(rowIndex: number, field: string): boolean
    isRowDirty(rowIndex: number): boolean
    isCellInvalid(rowIndex: number, field: string): boolean
    getCellValidationError(rowIndex: number, field: string): string | null
    invalidCells: CellValidationState[]
    canEditCell(rowIndex: number, field: string): boolean
    // row locking
    isRowLocked(rowOrId: T | unknown): boolean
    getRowLockInfo(rowOrId: T | unknown): RowLock | null
    lockRowById(id: unknown, lockerInfo?: Partial<RowLock>): boolean
    unlockRowById(id: unknown): boolean
    getExternalLocks(): Map<unknown, RowLock>
    clearExternalLocks(): void
    // row selection
    selectRow(rowIndex: number, mode?: 'replace' | 'toggle' | 'range'): void
    selectRowRange(fromIndex: number, toIndex: number): void
    clearSelection(): void                       rows + cell range + columns
    clearRowSelection(): void
    isRowSelected(rowIndex: number): boolean
    readonly selectedRows: T[]                   row objects, display order
    readonly selectedRowIndices: number[]
    copySelectedRowsToClipboard(): Promise<boolean>
    // cell / column selection
    selectCellRange(range: CellRange): void
    clearCellSelection(): void
    selectedCellRange: CellRange | null
    getSelectedCells(): CellContext<T>[]
    copyCellSelectionToClipboard(): Promise<boolean>
    selectColumn(colIndex: number, mode?: 'replace' | 'toggle' | 'range'): void   // colIndex = index in columns
    selectColumnRange(fromIndex: number, toIndex: number): void                  // on-screen span between them
    clearColumnSelection(): void
    getSelectedColumns(): Array<{ colIndex: number; field: string; column: Column<T> }>  // on-screen order; colIndex = index in columns
    isColumnSelected(colIndex: number): boolean
    selectAll(): void
    // tree
    isPathExpanded(path: string): boolean
    readonly expandedPaths: string[]
    toggleRowExpanded(path: string, options?: ExpandOptions): void
    expandRows(paths: string | string[], options?: ExpandOptions): void
    collapseRows(paths: string | string[], options?: ExpandOptions): void
    expandAll(paths?: string | string[] | null, options?: ExpandOptions): void
    collapseAll(paths?: string | string[] | null, options?: ExpandOptions): void
    getRowTreeInfo(row: T): { path: string; level: number; hasChildren: boolean } | null
    // columns
    setColumnWidth(field: string, width: string): void
    setColumnWidths(widths: ColumnWidthState[]): void
    getColumnWidthsState(): ColumnWidthState[]
    setColumnOrder(order: ColumnOrderState[]): void
    getColumnOrderState(): ColumnOrderState[]
    // focus / editing
    focusCell(rowIndex: number, colIndex: number): void
    startEditing(rowIndex: number, colIndex: number): void
    // menus / toolbar
    closeContextMenu(): void
    closeToolbar(): void
  }


----------------------------------------------------------------------
CONTEXTS
----------------------------------------------------------------------
All extend GridContext<T> (controller + element, non-enumerable).

  RowDataContext<T>    { row }                    getIdCallback, getIsRowEditableCallback,
                                                  column.getIsEditableCallback
  RowContext<T>        { row, rowIndex }          toolbar items, getRowClassCallback,
                                                  createDuplicateRowCallback, row locking
  CellContext<T>       { row, rowIndex, column, colIndex, field, value }
                                                  cell menu, row shortcuts, cell toolbar,
                                                  column callbacks
  FilterContext<T>     { row, column, field, filterValue }      column.filterCallback
  ValidateContext<T>   CellContext + { oldValue, source: 'edit' | 'paste' }
                                                  column.validateCallback (value = candidate)
  PasteValueContext<T> CellContext + { text }     column.getPasteValueCallback
  EditorContext<T>     CellContext + { commit(newValue), cancel() }
                                                  column.renderEditorCallback
  ValidationTooltipContext<T>  CellContext + { error }
                                                  getValidationTooltipCallback
  RowLockContext<T>    RowContext + { lockInfo }  rowLocking.getCanEditLockedCallback
  OptionContext<T>     { option }                 editorOptions.get*Callback
  OptionRenderContext<T>  { option, optionIndex, isFocused, isSelected, isDisabled }
                                                  editorOptions.renderOptionCallback
  OptionSearchContext<T>  CellContext + { term, signal }
                                                  editorOptions.searchCallback
  OptionSelectContext<T>  CellContext + { option }
                                                  editorOptions.onSelect
  RangeContext<T>      { rows, rowIndices, cellRange?, cells? }
                                                  rangeShortcuts
  HeaderMenuContext<T> { column: Column<T> | null, field, colIndex, sortDirection,
                         isFrozen, isTreeMode, allColumns, labels }
                                                  headerContextMenu, beforeHeaderMenuOpenCallback
                                                  (column null / field '' / colIndex -1 on the filler)
  FillContext<T>       { sourceCell: { rowIndex, colIndex, field, value },
                         targetCells: Array<{ rowIndex, colIndex, field }>,
                         direction: 'up' | 'down' | 'left' | 'right' }
                                                  beforeFillCallback
  BeforePasteContext<T> { rawText, parsedRows, hasHeaders, headerMapping,
                         targetRowIndex, targetColIndex, newRowsCount, skipCells }
                                                  beforePasteCallback (false cancels)
  CreateRowContext<T>  { data, rowIndex }         createRowCallback
  PaginationLabelsContext<T>  { currentPage, totalPages, totalItems, pageSize }
                                                  getPaginationLabelsCallback
  SummaryContext<T>    { items, allItems, totalItems, currentPage, pageSize, metadata }
                                                  renderSummaryCallback
  ChevronContext<T>    { row, isExpanded, hasChildren, level, path }
                                                  renderChevronCallback

COLUMN<T>
----------------------------------------------------------------------
Defines how a column renders, edits, and behaves.

  type Column<T> = {
    field: keyof T | string          REQUIRED. Data field name.
    title: string                    Column header text.
    headerInfo?: string              Info tooltip (shows i icon in header).
    width?: string                   e.g., '100px', '20%'
    minWidth?: string                Minimum width during resize.
    maxWidth?: string                Maximum width during resize.
    horizontalAlign?: 'left' | 'center' | 'right' | 'justify'
    verticalAlign?: 'top' | 'middle' | 'bottom'
    headerHorizontalAlign?: 'left' | 'center' | 'right' | 'justify'
    headerVerticalAlign?: 'top' | 'middle' | 'bottom'
    textOverflow?: 'wrap' | 'ellipsis'
    maxLines?: number                Line-clamp when textOverflow is 'wrap'.
    nowrap?: boolean                 Body cells never wrap.
    cellClass?: string               Static CSS class for all cells.
    getCellClassCallback?: (ctx: CellContext<T>) => string | null
    getDisplayValueCallback?: (ctx: CellContext<T>) => string     Display text (escaped)
    renderCellCallback?: (ctx: CellContext<T>) => string          Cell HTML (wins)
    isEditable?: boolean
    getIsEditableCallback?: (ctx: RowDataContext<T>) => boolean
    editor?: Editor
    editTrigger?: EditTrigger
    editorOptions?: EditorOptions<T>
    dropdownToggleVisibility?: ToggleVisibility
    shouldOpenDropdownOnEnter?: boolean
    validateCallback?: (ctx: ValidateContext<T>) => ValidateResult | Promise<ValidateResult>
    renderEditorCallback?: (ctx: EditorContext<T>) => void
    isEditButtonShown?: boolean
    getValidationTooltipCallback?: (ctx: ValidationTooltipContext<T>) => string | null
    tooltipMember?: string
    getTooltipCallback?: (ctx: CellContext<T>) => string | null
    isTooltipHtml?: boolean
    getCopyValueCallback?: (ctx: CellContext<T>) => string
    getPasteValueCallback?: (ctx: PasteValueContext<T>) => unknown
    filterCallback?: (ctx: FilterContext<T>) => boolean | null
    isFrozen?: boolean
    isResizable?: boolean             Default: true
    isReorderable?: boolean               Default: true
    isHidden?: boolean
    isSortable?: boolean
    isFilterable?: boolean
    fillDirection?: FillDirection
    isTree?: boolean                  Tree column (indentation + chevron)
  }

    options?: EditorOption[]
    valueMember?: string

    searchMember?: string
    iconMember?: string
    subtitleMember?: string
    disabledMember?: string
    groupMember?: string
    getValueCallback?: (ctx: OptionContext<T>) => string | number
    getDisplayValueCallback?: (ctx: OptionContext<T>) => string
    getSearchValueCallback?: (ctx: OptionContext<T>) => string
    getIconCallback?: (ctx: OptionContext<T>) => string
    getSubtitleCallback?: (ctx: OptionContext<T>) => string
    getIsDisabledCallback?: (ctx: OptionContext<T>) => boolean
    getGroupCallback?: (ctx: OptionContext<T>) => string
    renderOptionCallback?: (ctx: OptionRenderContext<T>) => string
    onSelect?: (ctx: OptionSelectContext<T>) => void
    isEmptyAllowed?: boolean
    labels?: { dropdownNoData?: string; dropdownNoResults?: string; dropdownSearching?: string; dropdownEmptyOption?: string }   per-column, over the grid labels
    dropdownMinWidth?: string
    placeholder?: string
    // Text
    maxLength?: number
    pattern?: string
    inputMode?: 'text' | 'numeric' | 'email' | 'tel' | 'url'
    editStartSelection?: EditStartSelection
    // Number
    min?: number
    max?: number
    step?: number
    decimalPlaces?: number

    falseValue?: unknown

    minSearchLength?: number
    debounceMs?: number
    multiple?: boolean
    maxSelections?: number
  }

  type EditorOption = { value: string | number | boolean, label: string, [key: string]: unknown }

----------------------------------------------------------------------
ACTION ITEMS (TOOLBAR, MENUS, SHORTCUTS)
----------------------------------------------------------------------
Built on @keenmate/web-components-core/actions (ActionItem / MenuItem /
MenuDivider). See toolbar-actions.txt.

  type GridRowAction    = 'add' | 'delete' | 'duplicate' | 'move-up' | 'move-down'
  type GridTreeAction   = 'expand' | 'collapse' | 'expand-subtree' | 'collapse-subtree' | 'expand-all' | 'collapse-all'
  type GridCellAction   = GridRowAction | GridTreeAction
  type GridHeaderAction = 'sort-asc' | 'sort-desc' | 'clear-sort' | 'hide-column'
                        | 'freeze-column' | 'unfreeze-column' | 'column-visibility'
                        | 'show-all-columns' | 'toggle-column'
  type GridAction       = GridCellAction | GridHeaderAction

  // Common item fields (ActionItem<Ctx, A>)
  {
    action?: A | 'custom'          built-in name; omit for a custom item
    id?: string                    identifies a custom item
    text?: string
    icon?: string
    tooltip?: string
    shortcut?: string
    cssClass?: string
    isVisible?: boolean            default true
    isDisabled?: boolean
    isDanger?: boolean
    isToggled?: boolean            toggle state (aria-pressed / aria-checked)
    getTextCallback?(ctx): string
    getIconCallback?(ctx): string
    getTooltipCallback?(ctx): string
    getClassCallback?(ctx): string | string[]
    getIsVisibleCallback?(ctx): boolean
    getIsDisabledCallback?(ctx): boolean
    getIsToggledCallback?(ctx): boolean
    onClick?(detail: ActionEventDetail): void | Promise<void>
  }

  // Menu items add (MenuItem<Ctx, A>)
  {
    children?: MenuEntry[]
    getChildrenCallback?(ctx): MenuEntry[] | Promise<MenuEntry[]>
    shouldCloseOnClick?: boolean   default true
  }

  type MenuDivider = { divider: true, text?: string }     (menuDivider(text?) builds one)

  interface GridToolbarItem<T> extends ActionItem<RowContext<T>, GridRowAction> {
    row?: number                   toolbar row, 1 = closest (default 1)
    isTextVisible?: boolean        show text next to the icon
  }
  type GridToolbarEntry<T>    = GridRowAction | GridToolbarItem<T> | MenuDivider       rowToolbar
  type GridMenuItem<T>        = MenuItem<CellContext<T>, GridCellAction>
  type GridMenuEntry<T>       = GridCellAction | GridMenuItem<T> | MenuDivider         contextMenu
  type GridHeaderMenuItem<T>  = MenuItem<HeaderMenuContext<T>, GridHeaderAction>
  type GridHeaderMenuEntry<T> = GridHeaderAction | GridHeaderMenuItem<T> | MenuDivider headerContextMenu
  interface GridShortcut<T> extends ActionItem<CellContext<T>, GridRowAction> {
    shortcut: string               required                                            rowShortcuts
  }
  interface GridRangeShortcut<T> extends ActionItem<RangeContext<T>, never> {
    shortcut: string               custom only                                         rangeShortcuts
  }

EVENT DETAILS AND GRIDEVENTMAP
----------------------------------------------------------------------
Events are DOM CustomEvents (bubble, not composed) plus camelCase on*
twins called with the detail. Every detail extends GridContext<T>.

  type GridEventMap<T> = {
    'row-change':            RowChangeEventDetail<T>            onRowChange
    'cell-edit-start':            EditEventDetail<T>                 onCellEditStart
    'cell-edit-cancel':           EditEventDetail<T>                 onCellEditCancel
    'validation-error':      ValidationErrorEventDetail<T>      onValidationError
    'focus-change':             FocusChangeEventDetail<T>             onFocusChange
    'row-delete':            RowDeleteEventDetail<T>            onRowDelete
    'cell-selection-change': CellSelectionChangeEventDetail<T>  onCellSelectionChange
    'row-selection-change':  RowSelectionChangeEventDetail<T>   onRowSelectionChange
    'column-selection-change': ColumnSelectionChangeEventDetail<T>  onColumnSelectionChange
    'data-request':          DataRequestEventDetail<T>          onDataRequest
    'filter-change':         FilterChangeEventDetail<T>         onFilterChange
    'column-resize':         ColumnResizeEventDetail<T>         onColumnResize
    'column-reorder':        ColumnReorderEventDetail<T>        onColumnReorder
    'expanded-change':         ExpandedChangeEventDetail<T>         onExpandedChange
    'row-lock-change':       RowLockChangeEventDetail<T>        onRowLockChange
    'cell-paste':        CellPasteEventDetail<T>        onCellPaste
    'action':                GridActionEventDetail<T>           onAction
  }
  type GridEventName = keyof GridEventMap

  EditEventDetail<T>            { row, rowIndex, field }
  ValidationErrorEventDetail<T> { row, rowIndex, field, error, source: 'edit' | 'paste' }
  RowDeleteEventDetail<T>       { row, rowIndex }      (a request; the grid does not delete)
  FilterChangeEventDetail<T>    { filters: Record<string, string> }
  RowChangeEventDetail<T>       = RowChangeDetail<T> & GridContext<T>
  FocusChangeEventDetail<T>        = FocusChangeDetail<T> & GridContext<T>
  CellSelectionChangeEventDetail<T> = CellSelectionChangeDetail & GridContext<T>
  DataRequestEventDetail<T>     = DataRequestDetail & GridContext<T>
  ColumnResizeEventDetail<T>    = ColumnResizeDetail & GridContext<T>
  ColumnReorderEventDetail<T>   = ColumnReorderDetail & GridContext<T>
  ExpandedChangeEventDetail<T>    = TreeExpandedChangeDetail & GridContext<T>
  RowLockChangeEventDetail<T>   = RowLockChangeDetail<T> & GridContext<T>
  CellPasteEventDetail<T>   = PasteDetail<T> & GridContext<T>

  // the `action` event (also each item's onClick and beforeActionCallback)
  type GridActionEventDetail<T> = surface fields & {
    action: GridAction | 'custom'
    id?: string
    item: ActionItem
    source: 'row-toolbar' | 'cell-toolbar' | 'context-menu' | 'header-menu' | 'keyboard'
    sourceEvent?: Event
    triggerElement?: HTMLElement
    dataset: Record<string, string>
  }
  Surface fields: row / rowIndex (+ column / colIndex / field / value on
  cell surfaces), HeaderMenuContext fields (header menu), rows /
  rowIndices / cellRange / cells (range shortcuts).
