PUBLIC METHODS
==============
@keenmate/web-grid - Complete reference for all public methods.


All methods are called on the <web-grid> DOM element:
  const grid = document.getElementById('grid')
  grid.focusCell(0, 1)

The same operations (plus a few more - see CONTROLLER below) are on
grid.controller, the public GridController facade that every callback ctx
and event detail also carries as `controller`:
  grid.onFocusChange = ({ rowIndex, controller }) => controller.focusCell(rowIndex, 0)


----------------------------------------------------------------------
FOCUS AND EDITING
----------------------------------------------------------------------

focusCell(rowIndex: number, colIndex: number): void
  Programmatically focus a cell. In navigate mode (editTrigger='navigate'),
  this sets the blue focus border on the specified cell. Does not start
  editing.

scrollToRow(rowIndex: number): Promise<boolean>
  Scroll the displayed row into view (virtual scroll aware). Resolves true
  once it is in view, false when the index is out of range / not rendered.

startEditing(rowIndex: number, colIndex: number): void
  Programmatically start editing a cell. The cell must be editable
  (column.isEditable = true, row not locked). Opens the appropriate
  editor for the column's editor type.

openCustomEditor(rowIndex: number, colIndex: number): void
  Open the custom editor for a cell with editor: 'custom'. Invokes the
  column's renderEditorCallback with the cell ctx + commit / cancel
  ({ row, rowIndex, column, colIndex, field, value, commit, cancel }).


----------------------------------------------------------------------
DRAFT MANAGEMENT
----------------------------------------------------------------------
Drafts are uncommitted cell edits. When a user edits a cell, the new value
is stored in a draft row until committed. Invalid values remain in the
draft but are flagged with validation errors.

getRowDraft(rowIndex: number): T | undefined
  Get the draft (edited but uncommitted values) for a row. Returns
  undefined if the row has no draft.

hasRowDraft(rowIndex: number): boolean
  Check if a row has any uncommitted changes.

getDraftRowIndices(): number[]
  Display indices of the displayed rows that have drafts.

getDrafts(): { row, draftRow, changedFields, isValid }[]
  Every draft — including rows on other pages, filtered out, or no longer in
  items (drafts are never pruned by setting items).

discardDraft(row: T): void
  Discard one row's draft (the row, its id-equal copy, or the draft object)
  and its invalid-cell markers.

discardAllDrafts(): void
  Discard all draft changes across all rows. Reverts every edited cell
  to its original value.

isCellDirty(rowIndex: number, field: string): boolean
  Check if a specific cell has been modified (draft value differs from original).

isRowDirty(rowIndex: number): boolean
  Check if any cell in a row has been modified (draft exists for that row).


----------------------------------------------------------------------
VALIDATION
----------------------------------------------------------------------

isCellInvalid(rowIndex: number, field: string): boolean
  Check if a cell has a validation error (from validateCallback or
  external invalidCells).

getCellValidationError(rowIndex: number, field: string): string | null
  Get the validation error message for a cell. Returns null if the cell
  is valid.

canEditCell(rowIndex: number, field: string): boolean
  Check if a cell can be edited. Considers:
  - Column isEditable setting
  - Row locking state and lockedEditBehavior
  - rowLocking.getCanEditLockedCallback result


----------------------------------------------------------------------
ROW IDENTIFICATION
----------------------------------------------------------------------
Rows are identified by idMember (default 'id') or getIdCallback.

getRowId(row: T): unknown | undefined
  Get the unique ID of a row: getIdCallback({ row }) when set, else
  row[idMember].

getRowById(id: unknown): T | null
  The row with this unique ID, or null if not found.

getRowIndex(row: T): number
  The row's display index (the rowIndex every ctx / event uses; follows
  sorting, filtering, paging), or -1 when it isn't displayed.


----------------------------------------------------------------------
ROW UPDATES
----------------------------------------------------------------------
For live data updates (WebSocket, polling). Requires row identification.

updateRowById(id: unknown, newData: Partial<T>): boolean
  Merge partial data into an existing row. Only the provided properties
  are updated; other properties remain unchanged. Returns true if the
  row was found and updated.

  grid.updateRowById(42, { status: 'approved', updatedAt: new Date() })

replaceRowById(id: unknown, newRow: T): boolean
  Replace an entire row object by ID. Returns true if the row was found
  and replaced.

  grid.replaceRowById(42, newRowData)


----------------------------------------------------------------------
ROW LOCKING
----------------------------------------------------------------------
Query methods accept either a row object or a row ID.
External lock methods identify rows by idMember (default 'id') or
getIdCallback.

isRowLocked(rowOrId: T | unknown): boolean
  Check if a row is locked (from any source: property, callback, or
  external).

getRowLockInfo(rowOrId: T | unknown): RowLock | null
  Get lock information for a row. Returns null if not locked.

lockRowById(id: unknown, lockerInfo?: Partial<RowLock>): boolean
  Lock a row externally. Returns true if the row was found. Fires the
  row-lock-change event (onRowLockChange).

  grid.lockRowById(42, {
    isLocked: true,
    lockedBy: 'Jane',
    lockedAt: new Date()
  })

unlockRowById(id: unknown): boolean
  Unlock an externally locked row. Returns true if the row was found
  and was locked.

getExternalLocks(): Map<unknown, RowLock>
  Get all external locks as a Map keyed by row ID.

clearExternalLocks(): void
  Remove all external locks at once.


----------------------------------------------------------------------
ROW SELECTION
----------------------------------------------------------------------

selectRow(rowIndex: number, mode?: 'replace' | 'toggle' | 'range'): void
  Select a row.
  'replace' (default): Clear existing selection, select this row
  'toggle': Toggle this row's selection without affecting others
  'range': Select all rows from last selected to this row

selectRowRange(fromIndex: number, toIndex: number): void
  Select a contiguous range of rows (inclusive).

clearSelection(): void
  Clear every selection kind: rows, the cell range and columns.

clearRowSelection(): void
  Clear only the row selection (clearCellSelection / clearColumnSelection
  clear the other kinds).

isRowSelected(rowIndex: number): boolean
  Check if a specific row is selected.

selectedRows: T[]                (property, read-only)
  The selected row objects, in display order.

selectedRowIndices: number[]     (property, read-only)
  Display indices of the selected rows, ascending.

copySelectedRowsToClipboard(): Promise<boolean>
  Copy selected rows as TSV (tab-separated values) to the clipboard.
  Returns true if successful. TSV format is compatible with Excel paste.


----------------------------------------------------------------------
CELL SELECTION
----------------------------------------------------------------------

selectCellRange(range: CellRange): void
  Select a rectangular cell range programmatically.
  CellRange: { startRowIndex, startColIndex, endRowIndex, endColIndex,
  startField, endField }

clearCellSelection(): void
  Clear the current cell range selection.

getSelectedCells(): CellContext<T>[]
  The cells of the current selection as cell contexts { row, rowIndex,
  column, colIndex, field, value }, row by row in on-screen column order.
  colIndex is the column index (data-col); the range itself
  (selectedCellRange.startColIndex / endColIndex) uses visual positions.

copyCellSelectionToClipboard(): Promise<boolean>
  Copy selected cells as TSV to clipboard. If shouldCopyWithHeaders is
  true, column headers are included as the first row. Returns true if
  successful.


----------------------------------------------------------------------
COLUMN WIDTH
----------------------------------------------------------------------

setColumnWidth(field: string, width: string): void
  Set the width of a single column.

  grid.setColumnWidth('name', '200px')

setColumnWidths(widths: ColumnWidthState[]): void
  Set widths for multiple columns at once.
  ColumnWidthState: { field: string, width: string }

  grid.setColumnWidths([
    { field: 'name', width: '200px' },
    { field: 'email', width: '300px' }
  ])

getColumnWidthsState(): ColumnWidthState[]
  Get current widths of all columns. Returns array of { field, width }.
  Same format used by localStorage persistence and setColumnWidths.


----------------------------------------------------------------------
COLUMN ORDER
----------------------------------------------------------------------

setColumnOrder(order: ColumnOrderState[]): void
  Set column display order.
  ColumnOrderState: { field: string, order: number }

  grid.setColumnOrder([
    { field: 'name', order: 0 },
    { field: 'email', order: 1 },
    { field: 'id', order: 2 }
  ])

getColumnOrderState(): ColumnOrderState[]
  Get current column order. Returns array of { field, order }.
  Same format used by localStorage persistence and setColumnOrder.


----------------------------------------------------------------------
TREE
----------------------------------------------------------------------

expandedPaths: string[]                    property (element: read a copy / assign = replace the
                                           state, no events; null = expandLevel default;
                                           controller: read-only)
isPathExpanded(path: string): boolean
toggleRowExpanded(path, options?): void    one row; row-expand / row-collapse + expanded-change
expandRows(paths: string | string[], options?): void
                                           one level (collapsed ancestors open too);
                                           row-expand per row that opened + expanded-change
collapseRows(paths: string | string[], options?): void
                                           row-collapse per row + expanded-change
expandAll(paths?: string | string[] | null, options?): void
                                           null = whole tree; paths = those rows + everything
                                           under them (ancestors open too)
collapseAll(paths?: string | string[] | null, options?): void
                                           (expandAll / collapseAll fire only expanded-change)
  options: ExpandOptions { isExclusive?: boolean  expand: collapse every other branch
                           isSilent?: boolean     no events }
  Tree mode (pathMember). expanded-change detail: { paths } (string[]).


----------------------------------------------------------------------
CONTROLLER (grid.controller)
----------------------------------------------------------------------
GridController<T> - the public facade. Available as grid.controller and
as `controller` on every callback ctx and event detail (non-enumerable).
It has the methods above (drafts, validation, row identification and
updates, locking, selection, columns, focusCell, startEditing, tree) plus:

Data
  items: T[]
  displayItems: T[]            rows as displayed (filtered, sorted, paginated, tree-collapsed)
  columns: Column<T>[]
  sort: SortState[]
  filters: Record<string, string>
  setFilter(field: string, value: string): void

Rows (what the add / delete / duplicate / move-up / move-down built-ins use)
  insertRow(row: T, afterRow?: T | null): void    insert after afterRow (items order), or at the end
  insertRows(rows: T[], afterRow?: T | null): void  same, several rows in order
  removeRow(row: T): void                         programmatic: no row-delete event
  removeRows(rows: T[]): void
  duplicateRow(row: T): T                         createDuplicateRowCallback, else a shallow copy
                                                  with idMember cleared; returns the copy
  moveRow(row: T, delta: -1 | 1): void            one displayed position up / down

Validation
  invalidCells: CellValidationState[]

Selection (same names as on the element)
  selectedRows: T[] / selectedRowIndices: number[]   read-only properties
  selectColumn(colIndex: number, mode?: 'replace' | 'toggle' | 'range'): void
    colIndex = index into columns (not the on-screen position)
  selectColumnRange(fromIndex: number, toIndex: number): void
    column indices; selects the on-screen span between them
  clearColumnSelection(): void
  getSelectedColumns(): SelectedColumn<T>[]
    [{ colIndex, field, column }] in on-screen order (colIndex = index in columns)
  isColumnSelected(colIndex: number): boolean
  selectAll(): void
  selectedCellRange: CellRange | null

Tree
  expandRows(paths, options?) / collapseRows(paths, options?)
  expandAll(paths?, options?) / collapseAll(paths?, options?)   null = whole tree
  getRowTreeInfo(row: T): { path, level, hasChildren } | null

Menus / toolbar
  closeContextMenu(): void
  closeToolbar(): void

Example (a custom toolbar item that archives the row):

  grid.rowToolbar = ['add', 'delete', {
    id: 'archive', icon: '📦', text: 'Archive',
    onClick: ({ row, controller }) => controller.removeRow(row)
  }]
