CV02 · Header Context Menu

Enable the predefined menu items 'column-visibility' and 'hide-column':

grid.headerContextMenu = [
    'sort-asc',
    'sort-desc',
    'clear-sort',
    { divider: true },
    'hide-column',        // hide this column (right-click target)
    'column-visibility'   // submenu with a toggle for each column
]

The 'column-visibility' submenu is generated dynamically from the current columns and shows a Show all entry plus one toggle per column.

CV03 · Programmatic API

Column visibility is controlled by the isHidden flag on each column. To trigger a re-render, reassign the columns array:

// Hide a specific column
grid.columns.find(c => c.field === 'email').isHidden = true
grid.columns = [...grid.columns]  // reassign to trigger re-render

// Show everything
grid.columns.forEach(c => c.isHidden = false)
grid.columns = [...grid.columns]
Why reassign?
The grid tracks changes via its setter. Mutating a column's isHidden in place won't trigger a render — spreading the array and reassigning does.

CV04 · API Reference

Property Type Description
column.isHidden boolean Hide a column while keeping it in the columns array (so visibility toggles know about it).
grid.headerContextMenu (string | object)[] Array of predefined items and custom entries. Include 'hide-column' and/or 'column-visibility'.
'column-visibility' string Submenu entry — auto-generates a toggle per column plus a Show all row.
