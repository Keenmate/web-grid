CS01 · Rainbow Salary + Inactive Rows

Demonstrates getCellClassCallback for value-based cell styling and getRowClassCallback for row-level styling.

  • Salary column: Rainbow gradient from red (low) through yellow/green to purple (high)
  • Inactive rows: Grayed out with reduced opacity

CS02 · Table Border Only (No Double Border)

When a grid with pagination is inside a card, you get a double border effect. Use isTableBorderOnly to place the border only around the table, letting pagination float outside.

Default (double border)

isTableBorderOnly={true}

// Default - border wraps everything including pagination
<web-grid ...></web-grid>

// Table border only - pagination floats outside the border
<web-grid table-border-only ...></web-grid>

CS03 · How It Works

1. getCellClassCallback (Column-level)

Returns a CSS class based on the cell context (value, row, column, …):

{
field: 'salary',
getCellClassCallback: ({ value, row }) => {
    if (value < 65000) return 'salary-1'
    if (value < 72000) return 'salary-2'
    // ... more ranges
    return 'salary-7'
}
}

2. getRowClassCallback (Grid-level)

Returns a CSS class for the entire row:

grid.getRowClassCallback = ({ row, rowIndex }) => {
if (row.status === 'Inactive') return 'row-inactive'
return null
}

3. getCustomStylesCallback (Required for Shadow DOM)

Injects CSS into the shadow root:

grid.getCustomStylesCallback = () => `
.salary-1 { background: #fee2e2 !important; }
.salary-2 { background: #ffedd5 !important; }
.row-inactive { opacity: 0.5; }
`

CS04 · customStyles — instance and page-wide CSS

customStyles (attribute custom-styles) puts CSS into one grid's shadow root; getCustomStylesCallback(ctx) computes it and wins. window.components['web-grid'].customStyles styles every grid on the page; it is applied first, so a grid's own CSS overrides it. Assigning it updates live grids. An @import (an icon font) is also linked once in the document head.

Page-wide CSS only

+ its own custom-styles (wins)

// every grid on the page
window.components['web-grid'].customStyles = `
.wg__header { background: #dbeafe; }
.wg__cell { color: #1e3a8a; }
`
// one grid — applied after the page layer, so it wins
<web-grid custom-styles=".wg__header { background: #fef3c7; }"></web-grid>
grid.customStyles = '.wg__cell { color: #92400e; }'
