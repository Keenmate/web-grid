ET01 · Edit Trigger: Click

Single click on a cell to start editing. Click another cell to immediately switch to editing that cell.

Test Scenarios
  • Click mode: Click Alice → edit mode. Click Bob → should immediately edit Bob (no double-click)
  • DblClick mode: Double-click to edit. Single click just focuses.
  • Navigate mode: Arrow keys to navigate, type to start editing, Enter/F2 to edit.
Edit Start Selection
  • mousePosition: Cursor placed where you clicked (default)
  • selectAll: All text selected
  • cursorAtEnd: Cursor at end of text
  • cursorAtStart: Cursor at beginning of text

ET02 · Empty Row (Inline Data Entry) Experimental

Add new rows directly in the grid using an empty row. Requires navigate mode (editTrigger: 'navigate').

⚠️ This feature is experimental — API may change in future releases.
Status: 0 saved 0 unsaved 0 invalid
How it works
  • Click a cell in the empty row (marked with +) and type to enter values
  • Press Tab to save the cell value and move to the next cell (doesn't commit row)
  • Press Tab on last cell to commit the row and start a fresh empty row
  • Press Enter to commit the row if it has any data
  • Committed rows are added to the items array
Validation Rules (for testing)
  • Name: Cannot be empty
  • Salary: Cannot be empty, must be less than 300
Test Data & Save Workflow
  • Copy buttons: Copy test data with 2 valid + 3 invalid rows
  • Paste: Click NAME cell in empty row, then Ctrl+V
  • Save button: Saves valid rows to fake "database" (200-500ms delay)
  • Invalid rows: Cannot be saved until errors are fixed

Try it: Paste test data → see status panel update → fix invalid cells → click Save

Requirements
  • editTrigger: 'navigate' - Navigate mode is required
  • isNewRowEnabled: true - Enable the empty row
  • createEmptyRowCallback - Provide a function to create new row objects

ET03 · Column-level editable vs Grid-level editable

When grid.isEditingEnabled = true, all columns are editable by default unless column.isEditable = false.

Column column.editor Notes
ID - NOT editable (isEditable: false)
Name 'text' Standard text input
Status 'select' Dropdown with fixed options
Dept 'combobox' Dropdown with text input
Country 'autocomplete' Searchable dropdown
Start Date 'date' Date picker
Active 'checkbox' Boolean toggle
Salary 'number' Numeric input
