BU01 · Employee Grid

A comprehensive example showing text, number, date, select, combobox, and autocomplete editors with keyboard navigation. Hover a Name or Salary cell: the getTooltipCallback tooltip is built from the cell context when it opens — select a row (click its #) or edit a salary and hover again to see the chip follow the row state.

BU02 · Keyboard Navigation

Navigate mode enables Excel-like keyboard navigation. Use the controls above to toggle it on/off.

Cell Navigation

  • Arrow Up/Down - Move between rows
  • Arrow Left/Right - Move between columns
  • Tab / Shift+Tab - Next/previous editable cell
  • Home / End - First/last cell in row
  • PageUp / PageDown - Move up/down by ~10 rows

Jump Navigation

  • Ctrl+Home - First cell in grid
  • Ctrl+End - Last cell in grid
  • Ctrl+PageUp - First cell in column
  • Ctrl+PageDown - Last cell in column
Editing Keys
  • Enter / F2 - Start editing the focused cell
  • Space - Toggle checkbox or open dropdown/datepicker
  • Escape - Cancel edit and clear focus
  • Type any character - Start editing with that character

BU04 · Tooltips on Keyboard Focus

A tooltip shows on keyboard focus as well as on hover: click a cell (or Tab into the grid), then move with the arrow keys — the Status and Note tooltips follow the focused cell after tooltip-show-delay. A focused cell keeps its tooltip while the mouse moves away; Escape hides it. The tooltip is role="tooltip" and the cell points to it with aria-describedby while it shows, so a screen reader reads it after the cell. Floating-toolbar buttons behave the same.

InputEffect
tooltipMember / getTooltipCallback (column)The cell's tooltip text (the callback wins; isTooltipHtml for HTML)
tooltip-show-delay / tooltipShowDelayDelay before it shows — hover and keyboard focus alike (default 200 ms)
tooltip-hide-delay / tooltipHideDelayDelay before it hides after the pointer leaves (default 100 ms)
EscapeHides the tooltip of the focused cell

BU05 · ARIA Grid and Screen Readers

The grid describes itself as an ARIA grid (a treegrid with tree data), so a screen reader announces the row and column position and the header of every cell it reaches — also with virtual scrolling, where only the visible rows exist in the DOM. Keyboard navigation stays Excel-like (focus moves cell to cell in edit-trigger="navigate").

Focused cell exposes: click a cell, then use the arrows

Screen-reader note

Screen readers read a page in browse mode and use their own table keys there. The grid's keys (arrows, Enter / F2 to edit, Space, Escape) need focus mode: NVDA and JAWS switch to it when a cell gets focus (Insert+Space toggles it in NVDA); with VoiceOver, interact with the table (VO+Shift+↓). Cell tooltips are read as the cell's description (BU04).
