RC01 · Basic Resize Demo

Hover over the right edge of any column header to see the resize handle. Drag to resize the column.

How it works
  • Hover over the right edge of a column header to reveal the resize handle
  • Click and drag to resize the column
  • Release to set the new width
  • Columns respect minWidth and maxWidth constraints

RC02 · With Persistence (storage-key)

Column widths (and order) are saved under storage-key and restored on page reload — by default in localStorage km-state:web-grid:resize-demo-grid; loadStateCallback / saveStateCallback keep them on your server instead. Try resizing a column, then refresh the page.

Configuration
  • storage-key="my-grid" / storageKey - Key of the persisted state (unset = off)
  • persist-column-widths / shouldPersistColumnWidths - Enable automatic width persistence
  • loadStateCallback / saveStateCallback - Keep the state yourself ({ key } / { key, state }, the whole state); set both — either one alone switches localStorage off
  • column-resize event / onColumnResize - Fired after resize with all column widths

RC03 · Per-Column Resize Opt-Out

Individual columns can disable resizing with isResizable: false. Try resizing the "Status" column - you can't!

RC04 · Per-Column Reorder Opt-Out

Individual columns can disable reordering with isReorderable: false. The first two columns (ID and Name) cannot be dragged, but you can still move other columns around them.

RC05 · With Frozen Panes

Resizable columns work with frozen panes. Frozen columns stay in place while you resize them or scroll horizontally.

Combining Features
  • Frozen columns can be resized - the sticky positioning adapts to the new width
  • Resizing a frozen column updates the left offset of subsequent frozen columns
  • Scroll horizontally to see frozen columns stay in place

RC06 · 🔀 Column Reorder by Dragging

Drag column headers to rearrange columns. Frozen columns cannot be reordered.

How it works
  • Hover over a non-frozen column header to see the grab cursor
  • Click and drag to move the column
  • A ghost element follows your cursor, and a drop indicator shows where the column will be placed
  • Frozen columns (highlighted) cannot be dragged or used as drop targets

RC07 · Virtual Scroll + Reorder + Resize

Combining all features: virtual scrolling with 10,000 rows, column reordering, and column resizing.

Features Combined
  • Virtual scroll renders only visible rows (10,000 total)
  • Drag column headers to reorder
  • Resize columns by dragging the right edge
  • Frozen columns stay in place while scrolling

RC08 · Header Context Menu

Right-click on column headers to access sort, hide, and freeze actions. Supports predefined actions and custom items.

Predefined Actions
  • sort-asc / sort-desc - Sort column
  • clear-sort - Clear sort (only shown if sorted)
  • hide-column - Hide the column
  • freeze-column / unfreeze-column - Freeze/unfreeze

RC09 · Configuration Options

Grid-Level Properties

storageKey (storage-key) Key of the persisted column state (localStorage km-state:web-grid:<key>, or the state callbacks)
shouldPersistColumnWidths (persist-column-widths) Enable automatic width persistence
isColumnReorderAllowed Enable drag-to-reorder columns
shouldPersistColumnOrder (persist-column-order) Enable automatic order persistence
onColumnResize Twin of the column-resize event, fired after column resize
onColumnReorder Twin of the column-reorder event, fired after column reorder

Column-Level Properties

isResizable Set to false to disable resize
minWidth Minimum column width (e.g., "50px")
maxWidth Maximum column width (e.g., "300px")

RC10 · Event Details

onColumnResize

The column-resize event (and its onColumnResize twin) carries a detail object with:

{
    field: "name",           // Which column was resized
    oldWidth: "150px",       // Previous width
    newWidth: "200px",       // New width
    allWidths: [             // All column widths
        { field: "id", width: "80px" },
        { field: "name", width: "200px" },
        ...
    ]
}

onColumnReorder

The column-reorder event (and its onColumnReorder twin) carries a detail object with:

{
    field: "email",          // Which column was moved
    fromIndex: 2,            // Original position (among non-frozen columns)
    toIndex: 0,              // New position (among non-frozen columns)
    allOrder: [              // All column orders
        { field: "email", order: 0 },
        { field: "department", order: 1 },
        { field: "name", order: 2 },
        ...
    ]
}

Use allWidths and allOrder to save column state to a database for per-user persistence.
