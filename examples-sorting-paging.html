SP05 · API

// Set initial sort
grid.sort = [
    { column: 'dept', direction: 'asc' },
    { column: 'name', direction: 'desc' }
]

// Page size selector
grid.pageSizes = [10, 25, 50, 100]
grid.pageSize = 25  // Current page size

// Pagination position
// Values: top-left, top-center, top-right,
//         bottom-left, bottom-center, bottom-right
grid.paginationPosition = 'bottom-right'
// Multiple positions with pipe separator:
grid.paginationPosition = 'top-right|bottom-right'

// Server-side pagination
grid.isPagingEnabled = true
grid.paginationMode = 'server'  // items are the current page; the grid doesn't slice
grid.totalItems = 500
grid.currentPage = 1
grid.isPaginationShown = true

// Handle data requests
grid.onDataRequest = (detail) => {
    // detail: { sort, page, pageSize, trigger, mode, skip }
    // trigger: 'sort' | 'page' | 'page-size' | 'filter' | 'init' | 'load-more'
    fetchData(detail).then(res => {
        grid.items = res.data
        grid.totalItems = res.total
    })
}

// Custom/translated labels
grid.getPaginationLabelsCallback = (ctx) => ({
    previous: '← Back',
    next: 'Forward →',
    pageInfo: `${ctx.currentPage}/${ctx.totalPages}`,
    itemCount: `${ctx.totalItems} records`,
    perPage: 'rows'
})

// Summary (aggregates, totals)
grid.summaryPosition = 'bottom-left'
grid.renderSummaryCallback = ({ allItems }) => {
  const total = allItems.reduce((s, r) => s + r.salary, 0)
  return `<strong>Total:</strong> $${total.toLocaleString()}`
}

// Server-side: use metadata for aggregates
grid.renderSummaryCallback = ({ metadata }) => {
  return `<strong>Total:</strong> $${metadata?.total || 0}`
}
grid.summaryMetadata = serverResponse.aggregates

// Same area = share row (default: true)
grid.summaryPosition = 'bottom-left'
grid.paginationPosition = 'bottom-right'
grid.isSummaryInline = true  // Share row when in same area
// Result: [Summary] -------- [Pagination]

// Separate rows
grid.isSummaryInline = false  // Each on its own row

// Filter row (SP06): contains, case- and accent-insensitive
grid.isFilteringEnabled = true        // attribute: enable-filtering
grid.columns = [{ field: 'name', isFilterable: true }]
grid.filters = { name: 'zoe' }        // matches 'Zoë' too
grid.onFilterChange = ({ filters }) => { /* … */ }

// Page-wide labels (SP07): every grid / component on the page
window.components.locale = {
    locale: 'cs-CZ',
    labels: { 'web-grid.labels.itemCount': 'Položky: {ctx.count}' }   // ONE flat dictionary of full keys
}
window.components.locale = null       // back to English
// Per key: instance grid.labels → page-wide → English

SP06 · Filter Row: Accent-Insensitive Matching

enable-filtering shows a filter input under every column with isFilterable: true. Matching is contains, case- and accent-insensitive, and the typed term is trimmed: try zoe (finds Zoë), muller (Müller), sevcik (Ševčík) or CAFÉ (café).

Active filters: none

SP07 · Page-Wide Labels (window.components.locale)

One assignment translates every grid on the page — and every other Keenmate component: window.components.locale = { locale, labels: { 'web-grid.labels.itemCount': '…', … } } — one flat dictionary of full <component>.<elementType>.<name> keys. Per key, the instance labels win, then the page-wide labels, then English. Numbers in a label follow the page locale (1 234 položek in Czech). The button affects the whole page: the grids above switch too, except where an instance getPaginationLabelsCallback sets its own text (SP03). Every localization layer (instance labels, translateCallback, locale formatting) is on Localization.
