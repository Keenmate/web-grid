EF02 · Navigate Mode (Excel-like)

Click a cell to focus, then use keyboard to navigate and edit:

  • Arrow keys Move between cells
  • Tab / Shift+Tab Next/previous cell
  • Enter / F2 Enter edit mode
  • Space Toggle checkbox or open dropdown
  • Escape Cancel editing
  • Any character Start typing to edit

EF03 · Validation with validateCallback

Validation rules applied to each column. Invalid cells remain marked until fixed:

  • Name: Required, minimum 2 characters
  • Age: Must be 0-150
  • Score: Must be 0-100 (rounds to integer)
  • Email: Must contain @
