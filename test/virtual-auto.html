virtual-auto fixture

Targeted by e2e/virtual-auto.spec.ts. Virtual scroll is off by default; enable-virtual-scroll="auto" (property null) opts in to automatic: virtual once the row count reaches virtual-scroll-threshold. Rows are set by the spec through window.setRows(n, id). Reload resets all state.

#grid — no enable-virtual-scroll (default off), default threshold (100)

#auto — enable-virtual-scroll="auto", threshold 20

#forcedOn — enable-virtual-scroll, threshold 20

#forcedOff — enable-virtual-scroll="false", threshold 20
