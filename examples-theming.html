TH02 · Tooltip width

Every grid tooltip (cell, validation, header info, toolbar) sizes its content box with --wg-tooltip-width (auto = shrink to the text), floored by --wg-tooltip-min-width (0) and capped by --wg-tooltip-max-width (300px, long text wraps). Padding comes on top. Hover a Note cell; leave a field empty for the default.

TH03 · How the precedence works

The grid resolves its rendered theme by walking signals in this order, highest priority first:

  1. Per-instance data-theme on the <web-grid> element — always wins if set.
  2. Theme signal (data-theme, data-bs-theme, .dark, .light) on <html> / <body>, or on the nearest ancestor that has one when the grid sets theme-source="closest" (as the demo grid does) — detected by @keenmate/web-components-core and mirrored onto the grid as data-context-theme.
  3. Page color-scheme — when set to dark or light, the light-dark() fallbacks in variables.css resolve accordingly via inheritance.
  4. OS preference — only takes effect when the page declares color-scheme: light dark and no other signal above is set.
