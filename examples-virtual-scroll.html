VS01 · Virtual Scroll (10,000 rows)

Virtual scrolling only renders visible rows + buffer, enabling smooth scrolling through massive datasets. The grid calculates which rows to display based on scroll position.

Total rows: 10,000 Rendered rows: ~25 Row height: 38px Buffer: 10 rows

VS02 · Infinite Scroll (Load More)

Loads 1,000 items initially, then loads 1,000 more each time you scroll near the bottom (up to 10,000 total). Combined with virtual scroll for optimal performance.

Loading 1,000 more items...

Loaded items: 1,000 Has more: Yes Batch size: 1,000 Max items: 10,000

VS03 · Virtual Scroll API

// Enable virtual scroll explicitly
grid.isVirtualScrollEnabled = true

// Or auto-enable via threshold
grid.virtualScrollThreshold = 100  // Enable when >= 100 items

// Configure row height (must match CSS)
grid.virtualScrollItemHeight = 38  // Default: 38px

// Buffer rows above/below viewport
grid.virtualScrollOverscan = 10  // Default: 10

// Check if virtual scroll is active
if (grid.shouldUseVirtualScroll()) {
  console.log('Virtual scroll is active')
}

VS04 · Infinite Scroll API

// Enable infinite scroll
grid.isInfiniteScrollEnabled = true

// Distance from bottom to trigger (px)
grid.infiniteScrollThreshold = 100  // Default: 100px

// Control loading state
grid.hasMoreItems = true  // Set false when done

// Handle load more events
grid.onDataRequest = async (detail) => {
  if (detail.trigger === 'load-more') {
    // detail.mode = 'append'
    // detail.skip = current item count
    const more = await fetchMore(detail.skip)
    grid.items = [...grid.items, ...more]
    grid.hasMoreItems = more.length === pageSize
  }
}

VS05 · DataRequestDetail (Extended)

type DataRequestDetail = {
  sort: SortState[]      // Current sort state
  page: number           // Current page (for pagination)
  pageSize: number       // Items per page
  trigger: DataRequestTrigger  // What triggered: 'sort' | 'page' | 'page-size' | 'init' | 'load-more'
  mode: 'replace' | 'append'   // How to handle response
  skip: number           // Items to skip (offset for server)
}

// Usage
grid.onDataRequest = (detail) => {
  if (detail.mode === 'append') {
    // Infinite scroll - append to existing
    fetchData({ skip: detail.skip, take: 50 }).then(data => {
      grid.items = [...grid.items, ...data]
    })
  } else {
    // Normal ops - replace items
    fetchData({ skip: detail.skip, take: detail.pageSize }).then(data => {
      grid.items = data
    })
  }
}
